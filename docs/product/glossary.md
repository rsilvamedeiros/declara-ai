# Glossário

Status: rascunho. Definições fiscais devem ter fonte oficial antes de virarem regra; aqui ficam como vocabulário do projeto.

| Termo | Significado no projeto |
|---|---|
| IRPF | Imposto de Renda da Pessoa Física |
| Ano-calendário | Ano em que os rendimentos e despesas ocorreram |
| Exercício | Ano em que a declaração é entregue (referente ao ano-calendário anterior) |
| Ficha | Seção da declaração do IRPF (ex.: Rendimentos Tributáveis, Pagamentos Efetuados) |
| Titular | Pessoa que declara |
| Dependente | Pessoa cujas despesas e rendimentos podem entrar na declaração do titular, conforme regras vigentes |
| Informe de rendimentos | Documento emitido por fontes pagadoras e instituições financeiras com os valores do ano |
| Modelo completo | Declaração com deduções legais comprovadas |
| Modelo simplificado | Declaração com desconto padrão no lugar das deduções |
| Carnê-leão | Recolhimento mensal obrigatório de certos rendimentos recebidos sem retenção na fonte |
| DARF | Documento de Arrecadação de Receitas Federais |
| Malha fina | Retenção da declaração para conferência por inconsistência de dados |
| Documento de origem | Arquivo enviado pelo usuário do qual um dado foi extraído |
| Campo extraído | Valor lido de um documento, com página, trecho e confiança |
| Catálogo de regras | Conjunto versionado de regras fiscais por ano, cada uma com fonte oficial e vigência |
| Validação | Verificação determinística que gera um alerta com severidade |
| Roteiro | Guia de preenchimento ficha a ficha para o programa da Receita |
